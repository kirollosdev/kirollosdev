# Hi, I'm Kirollos Magdy 👋

**WordPress Developer** building custom WordPress, WooCommerce and Elementor websites for businesses in Canada, Germany, the UAE, Saudi Arabia, Bahrain, Libya and Egypt. Based in Egypt, working remotely.

I turn designs into fast, secure websites that clients can edit themselves, and I write the custom code when a plugin is not enough.

## What I build

- **Custom WordPress websites** from Figma designs, with Elementor, Elementor Pro or custom themes
- **WooCommerce stores** with payment gateway integrations (Stripe, PayPal, Square, Visa and Mastercard processing, wallets and regional gateways) and API sync with business systems
- **Custom plugins and Elementor widgets** in PHP and JavaScript
- **Multilingual and Arabic RTL websites** with WPML and TranslatePress
- **Speed and security work**: Core Web Vitals, caching, backups and hardening
